# School Meal

A minimal, iPhone-inspired school meals application that archives NEIS breakfast, lunch and dinner for all seven days of the week and analyzes historical menus and nutrition.

Stack: Next.js, TypeScript, Neon PostgreSQL, Vercel.

Configuration: set `DATABASE_URL`, `NEIS_API_KEY`, `CRON_SECRET` on the server. Never commit credentials.

The existing school information repository remains separate.
